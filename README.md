# SQL Practice — LeetCode SQL 50

Решения задач из [LeetCode SQL 50](https://leetcode.com/studyplan/top-sql-50/) на PostgreSQL.

## Что внутри

- **01_select** — базовые SELECT, фильтрация
- **02_basic_joins** — JOIN всех типов
- **03_aggregate_functions** — GROUP BY, агрегаты
- **04_sorting_and_grouping** — ORDER BY, HAVING
- **05_advanced_select_and_joins** — оконные функции, self join
- **06_subqueries** — CTE, коррелированные подзапросы
- **07_string_functions_regex** — работа со строками, регулярки

## Стек

- PostgreSQL
